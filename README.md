# Superhero 5th Birthday Celebration Website

An interactive, animated 3D Superhero Birthday celebration website for a 5-year-old boy curious about superheroes!

## 🌟 Features
- 🦸‍♂️ **3D Flying Superhero World**: Three.js 3D universe with animated flying hero, waving cape, and floating balloons.
- 🎂 **Interactive 3D Cake Ceremony**: 5 superhero candles with live sparklers, blow-out flame physics, and multi-stage fireworks.
- 💌 **3D Pop-Up Greeting Card**: Realistic 3D folding card with custom personal birthday wishes.
- 📸 **Hero Photo Collage & Vault**: Drag-and-drop 3D polaroid frames with persistent browser memory.
- 🎮 **3 Fun Mini-Games**: Villain Bubble Pop, Treat Catch, and Hero Badge Memory Match.
- ⚡ **Superhero HQ**: Superpower DNA scanner, 8-sound comic soundboard, and suit customizer.
- 🔊 **Web Audio Synthesizer**: Pure browser-generated lasers, fanfare, and birthday melodies.
